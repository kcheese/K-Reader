# K-Reader

A personal Android reader for manga and light novels.

- **Manga** from online sources through Mihon-compatible extensions (no extension repositories are included; add your own).
- **Light novels** from your own EPUB and PDF files, organised into series with covers, a manual volume order and reading progress.

Download the latest version from [Releases](../../releases). Once installed, the app checks this page for updates itself.

## Credits and licence

K-Reader is a modified version of [Mihon](https://github.com/mihonapp/mihon), used under the Apache License 2.0. Changes from Mihon include:

- a Novels library and reader for EPUB and PDF files, built on the [Readium Kotlin Toolkit](https://github.com/readium/kotlin-toolkit) (BSD 3-Clause)
- new name, icon and app ID
- the Library tab renamed Manga, and Updates moved into More

The full list of open-source libraries and their licences is in the app under **More → About → Open source licenses**.
